03 设计原则

一套公式，撑起所有中国色

中国色主题不是一张张调出来的，而是按固定规则推导：背景、候选字、标签三档灰固定， 强调色同时决定「选中文字」和「选中背景」。改一个色值，整套主题就成立。

  • 01

    亮色：三档灰 + 一个强调色

    背景 #FFFFFF，候选字 #454545，未选中标签 #8E8E8E。强调色负责「被选中」的那一下。

  • 02

    选中背景 = 强调色淡一层

    选中文字直接用强调色本身，背景取同色 0x26 透明度（约 15%），既有存在感又不抢戏。

  • 03

    暗色：换底不换逻辑

    背景转 #000000，候选字 #BABABA，标签 #717171；强调色改为铺满整个选中块，文字转白。

  • 04

    成对生成，而不是各调各的

    脚本读一行 #207F4C,bohelv,薄荷绿，就同时吐出亮色与 _dark 两套，避免深浅色各自跑偏。

04 快速开始

四步，换掉输入法皮肤

不需要懂 Rime 的补丁语法，也不用改注册表。拿到 weasel.custom.yaml， 放进用户文件夹、重新部署，就生效了。

准备配色清单

每行一种颜色：配色 16 进制,英文名,中文名。想要现成的就直接用仓库里的 scripts/colors.csv。

运行生成脚本

Python 3 或 JDK 15+ 都能跑；懒得配环境就用 PowerShell 版，自动下载并执行。

得到配置文件

输出一份 weasel.custom.yaml，里面是 preset_color_schemes 与默认的 style 设置。

放进用户文件夹并部署

复制到 %APPDATA%\Rime，右键小狼毫托盘图标选「重新部署」，之后在「方案选单 → 输入法设定」里挑配色。

# 把 scripts/colors.csv 与 generate.py 放到同一目录
# 在该目录打开终端，然后运行
python generate.py
# 需要 JDK 15+（Generate.java 用了文本块语法）
# colors.csv 与 Generate.class 放在同一目录
java Generate
# 允许执行远程脚本（仅当前用户，可撤销）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 下载 install.ps1 并执行，自动写入 $env:appdata\rime
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/rxhaol/easy-configs-rime/refs/heads/main/scripts/install.ps1" -UseBasicParsing | Select-Object -ExpandProperty Content | Invoke-Expression
远程脚本默认写入 $env:appdata\rime。如果你改过 Rime 用户文件夹位置，建议先 clone 仓库、调整 install.ps1 的目标路径再执行。

05 自助调整

再顺手一点，就自己改

主题只管颜色；候选框的大小、留白、圆角归 style 节点管。仓库那张示意图用 CSS 盒模型解释了一遍， 对照着改数值即可。

weasel.custom.yaml
style:
  font_face: "PingFang SC:Bold"   # 字体
  font_point: 12                    # 字号
  horizontal: true                # 横排候选
  blur: true                      # 毛玻璃
  layout:
    border: 2                     # 边框宽度
    round_corner: 5              # 圆角
    candidate_spacing: 14         # 候选词间距
    hilite_padding: 4             # 选中块高度
    hilite_spacing: 2             # 序号与文字间距
    margin_x: 6                  # 左右边距
    margin_y: 6                  # 上下边距
    spacing: 5                   # 候选区与输入区间距
candidate_spacing候选词之间的距离，想做紧凑键盘就调小
hilite_padding选中色块的高度，直接影响候选条的「呼吸感」
hilite_spacing序号与候选字之间的空隙
margin_x / margin_y整个候选框的左右、上下内边距
