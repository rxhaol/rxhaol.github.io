用 VitePress 搭一个带毛玻璃卡片的个人主页 ​

以前我的个人主页是一个手写的 index.html，加一个作品就要手动复制一段 HTML。做到第 8 个作品的时候我终于受不了了：改一次导航要开 12 个文件，博客更是完全没动力写。

所以我换成了 VitePress：所有内容都是 Markdown，列表和侧边栏自动生成，改一次配置全站生效。

为什么是 VitePress ​

我比较过几套方案：

方案优点我不选的原因
手写 HTML完全可控加内容成本太高，没有博客能力
Hexo / Hugo博客生态成熟主题定制要啃别人的模板，改样式很痛苦
Astro灵活、性能好我只需要静态文档站，配置成本偏高
VitePressMarkdown 驱动、Vue 组件、默认主题够用——

决定性的一点是：VitePress 允许我在 Markdown 里直接写 Vue 组件。作品网格、博客列表这些「数据驱动」的部分，我可以封装成组件，而正文部分继续用 Markdown 写。

整体结构 ​

站点的目录结构是这样的：

text
docs/
├─ .vitepress/
│  ├─ config.mts          # 导航、侧边栏、SEO
│  ├─ site.config.ts      # ★ 个人信息 + 作品数据（日常只改这里）
│  ├─ utils/posts.ts      # 构建时读取文章，生成侧边栏
│  └─ theme/
│     ├─ index.ts         # 注册全局组件、加载样式
│     ├─ styles/          # 配色变量 + 毛玻璃参数
│     └─ components/      # 作品卡片、博客列表、首页 Hero
├─ index.md               # 首页
├─ projects/              # 作品集
└─ blog/posts/            # 博客文章

关键设计是数据和内容分离：

  • 作品是结构化数据（名称、描述、标签、链接），放在 site.config.ts，用卡片组件渲染成网格
  • 博客就是普通的 Markdown 文件，放进 blog/posts/ 就会自动出现在列表、标签和侧边栏里

现代配色和毛玻璃卡片是怎么做的 ​

VitePress 的默认主题全部基于 CSS 变量，所以换肤不用改任何组件代码，只要覆盖变量。我把强调色定成靛蓝：

css
:root {
  --vp-c-brand-1: #4f46e5;   /* 链接、主按钮 */
  --vp-c-brand-2: #4338ca;   /* 悬浮态 */
  --vp-c-brand-3: #6366f1;
  --vp-c-brand-soft: rgba(99, 102, 241, 0.14);

  /* 渐变两端，用于按钮和标题装饰条 */
  --vc-accent-from: #6366f1;
  --vc-accent-to: #8b5cf6;

  /* 底色不是纯白，带一点冷调灰，看起来没那么生硬 */
  --vp-c-bg: #f6f7fb;
  --vp-c-text-1: #1c2033;
}

颜色只用在一处：强调色。卡片、导航、正文全是中性色，靠这一点靛蓝统一点缀，所以不会出现满屏色块。

毛玻璃卡片的关键 ​

毛玻璃（backdrop-filter）有个容易踩的坑：它模糊的是「背后已经画上去的内容」。如果页面背景是纯色，卡片半透明之后只会透出那个纯色，看起来就是一块灰，完全不像玻璃。

所以必须先在页面底层铺点东西。我在 body 上放了三团固定不动的低饱和光斑：

css
body {
  background-color: var(--vp-c-bg);
  background-image:
    radial-gradient(820px 560px at 6% -8%, rgba(99, 102, 241, 0.2), transparent 62%),
    radial-gradient(680px 500px at 94% 2%, rgba(56, 189, 248, 0.16), transparent 64%),
    radial-gradient(760px 600px at 78% 100%, rgba(168, 85, 247, 0.15), transparent 64%);
  background-repeat: no-repeat;
  background-attachment: fixed;   /* 滚动时光斑不动，玻璃效果更稳定 */
}

.vc-card {

.vc-card:hover {

  background: rgba(255, 255, 255, 0.78);

现代感主要来自这几件事：

  1. 毛玻璃材质：半透明底 + backdrop-filter，卡片像是浮在背景上
  2. 大圆角 + 双层阴影：18px 圆角，近处一层描边感、远处一层氛围
  3. 紧凑字距：大标题用负 letter-spacing（-0.04em），字号越大收得越紧
  4. 克制的强调色：只有靛蓝一处彩色，其余全是中性色

模糊值别开太大

blur(16px) 已经够了。开到 30px 以上文字边缘会发虚，而且每张卡片都是一次 GPU 合成，卡片一多就掉帧。

深色模式要换一套参数

半透明白卡放到深色背景上会变成一块脏灰色。深色模式的玻璃要用「低亮度半透明表面 + 8% 白色细边框」，模糊保留但透明度要降下来，阴影也几乎不参与分层。

覆盖样式的顺序不能反

在 theme/index.ts 里必须先 import 默认主题，再 import 自己的 CSS，否则你的变量会被默认主题盖掉，改了没反应。

博客列表为什么不用插件 ​

很多 VitePress 博客模板会引入一堆插件来做文章列表。其实内置的 createContentLoader 就够了：

ts
import { createContentLoader } from 'vitepress'

export default createContentLoader('blog/posts/*.md', {
  excerpt: '<!-- more -->',
  transform(raw) {
    return raw
      .map(({ url, frontmatter, excerpt }) => ({
        url,
        title: frontmatter.title,
        date: frontmatter.date,
        tags: frontmatter.tags ?? [],
        description: frontmatter.description || excerpt
      }))
      .sort((a, b) => (a.date < b.date ? 1 : -1))
  }
})

写在最后 ​

换成 VitePress 之后，我写博客的流程变成了：

bash
pnpm new "文章标题"   # 生成带 frontmatter 的 Markdown 文件
pnpm dev             # 本地预览
git push             # 自动部署到 GitHub Pages
