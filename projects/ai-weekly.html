AI 周报生成器 ​

把零散的 Git 提交记录和聊天记录丢进去，自动生成一份人话周报。

解决什么问题 ​

每周五写周报要花我大概四十分钟，其中大部分时间不是在写，而是在回忆这周做了什么。Git 提交记录是 fix: typo，聊天记录是「那个问题好了」，从这些碎片里拼出一份能看的文档纯粹是体力活。

效果 ​

bash
npx weekly-report --notes ./notes.md --out ./weekly.md
1

十几秒后得到一份 300 字左右、按主题归类的周报，可以直接粘贴进公司的周报系统。

技术选型 ​

部分选择原因
运行形态Node.js CLI自己用的工具，命令行最快，不需要界面
数据来源git log + 本地 Markdown 笔记不碰公司系统，没有权限问题
清洗正则规则过滤比调提示词便宜得多，也更稳定
生成OpenAI API中文归纳效果好，接口简单

核心实现 ​

1. 取数据 ​

js
import { execFileSync } from 'node:child_process'

const output = execFileSync('git', [
  'log',
  '--since=7 days ago',
  '--pretty=format:%h|%an|%ad|%s',
  '--date=short'
], { encoding: 'utf-8' })

2. 过滤噪音 ​

真实提交里大约一半是 typo、wip、Merge branch 这类内容，先过滤掉再送给模型，输出质量提升非常明显。

3. 生成周报 ​

提示词里最重要的两条约束是「总长度 300 字以内」和「不要编造记录里没有的信息」。没有后者的时候，它给我编过不存在的功能上线记录。

踩过的坑 ​

长输入会被静默截断

提交特别多的一周，输入超过 6000 字符后有一半被丢掉了。现在会先做一次摘要再生成。

周一运行会把上周五算进来

用 7 days ago 取数据并不等于「本周」。改成按自然周计算周一到周五。

后续计划 ​
